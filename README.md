# Material Educativo · MetodologIA 2026

Repositorio público con material educativo abierto de **MetodologIA**: bibliotecas, playbooks, cartillas, skills y paquetes de aprendizaje para apropiación práctica de IA por personas reales.

**Brand voice:** MetodologIA v3.0 · navy `#122562` · gold `#FFD700` · blue `#137DC5`
**Lema:** Metodo primero, (Gen)AI Después.
**License:** CC BY-NC-SA 4.0
**Diseñador:** Javier Montaño · Founder/CEO MetodologIA

## Navegación principal

| Familia | Carpeta | Qué contiene |
|---|---|---|
| Biblioteca Universal | [`biblioteca/`](biblioteca/) | HTML self-contained, JSON canónico v3.0, JSON minificado y bundle Prompster. |
| Prompting Universal | [`prompting-universal/`](prompting-universal/) | Cartilla consolidada sobre SPEC, PIVOTE, DSVSR, pipeline `/0-/9`, 100 ✓ y modos de trabajo. |
| Programa de Empoderamiento | [`programa-empoderamiento/`](programa-empoderamiento/) | Cartilla del programa y oferta de tres talleres de onboarding cada dos meses, 25 inscritos por cohorte. |
| Jarvis OS en Claude | [`claude-jarvis/`](claude-jarvis/) | Playbook, Runbook, Masterclass y Workbook para montar Jarvis OS sobre Claude. |
| Cartillas IA | [`cartillas-ia/`](cartillas-ia/) | ChatGPT, Gemini, Kimi, NotebookLM y comparativa 2026. |
| Ciencia del aprendizaje | [`estudio/`](estudio/) | Cartilla de técnicas de estudio basadas en evidencia. |

## Cómo usar

Abre [`index.html`](index.html) o entra a la carpeta de la familia que necesites. Cada subcarpeta tiene un `README.md` con audiencia, archivos y canon.

```bash
git clone https://github.com/JaviMontano/material-educativo-metodologia.git
cd material-educativo-metodologia
open index.html
```
