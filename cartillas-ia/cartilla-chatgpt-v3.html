Sistema de Memoria [DOC]Memory System [DOC]

ChatGPT tiene tres niveles de memoria: (1) Conversación actual — todo lo dicho en este chat. (2) Memoria persistente — hechos que el modelo recuerda entre conversaciones (preferencias, nombre, trabajo). (3) Projects — instrucciones y archivos que aplican a todas las conversaciones dentro de ese proyecto. Los tres se combinan para dar contexto, pero la memoria persistente tiene un límite de hechos almacenados.ChatGPT has three memory levels: (1) Current conversation — everything said in this chat. (2) Persistent memory — facts the model remembers across conversations (preferences, name, job). (3) Projects — instructions and files that apply to all conversations within that project. All three combine for context, but persistent memory has a stored-facts limit.

Agent Mode (Atlas) [INFERENCIA]

Agente autónomo que navega la web via el browser Atlas. Arquitectura CUA (Computer-Using Agent): ve la pantalla pixel por pixel, hace clic, llena formularios, ejecuta workflows multi-paso. Pulse Dashboard muestra un timeline en tiempo real de cada acción del agente, con Decision Gateways donde solicita confirmación explícita antes de acciones irreversibles (compras, envios, borrados).Autonomous agent that browses the web via the Atlas browser. CUA architecture (Computer-Using Agent): sees the screen pixel by pixel, clicks, fills forms, executes multi-step workflows. Pulse Dashboard shows a real-time timeline of each agent action, with Decision Gateways that request explicit confirmation before irreversible actions (purchases, submissions, deletions).

Cuándo usar: tareas web repetitivas — reservas de vuelos, comparación de precios, llenado de formularios, recopilación de datos de múltiples sitios. Cada misión dura entre 5-30 min dependiendo de la complejidad. El agente maneja tabs múltiples y sigue flujos de navegación complejos.When to use: repetitive web tasks — flight bookings, price comparison, form filling, data collection from multiple sites. Each mission takes 5-30 min depending on complexity. The agent handles multiple tabs and follows complex navigation flows.

Falla en: CAPTCHAs (no puede resolverlos), MFA/2FA (no puede completar verificación en dos pasos), sitios con detección anti-bot agresiva (Cloudflare challenge pages, rate limiting estricto). No puede acceder a sesiones autenticadas del usuario ni leer emails de verificación.Fails on: CAPTCHAs (cannot solve them), MFA/2FA (cannot complete two-factor verification), sites with aggressive anti-bot detection (Cloudflare challenge pages, strict rate limiting). Cannot access user's authenticated sessions or read verification emails.

Edge case: En sitios con layouts dinámicos (SPAs pesadas, infinite scroll), el agente puede perder el rastro de elementos. Monitorea via Pulse y retoma manualmente si se atasca.Edge case: On sites with dynamic layouts (heavy SPAs, infinite scroll), the agent may lose track of elements. Monitor via Pulse and manually resume if stuck.

Context rot documentado [DOC]Documented context rot [DOC]

El contexto utilizable real es inferior al teórico. Aunque se anuncian 128K-1M tokens, se observa degradación progresiva ("context rot") en la calidad de respuestas cuando se superan ~60-80K tokens de entrada, especialmente en instrucciones ubicadas al centro del prompt.Actual usable context is lower than theoretical. Although 128K-1M tokens are advertised, progressive quality degradation ("context rot") is observed when exceeding ~60-80K input tokens, especially for instructions located in the middle of the prompt.

!

Sites with aggressive anti-bot protection block the agent.
