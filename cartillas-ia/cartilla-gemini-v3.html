Sistema de Contexto [DOC]Context System [DOC]

Gemini tiene tres niveles de contexto: (1) Conversacion actual — todo lo dicho en este chat, hasta 2M tokens. (2) Workspace context — acceso a Gmail, Drive, Docs cuando esta conectado (AI Pro+). (3) Gems — instrucciones persistentes que aplican en cada uso del Gem. A diferencia de ChatGPT que tiene memoria persistente explicita entre conversaciones, Gemini depende mas de Workspace como fuente de contexto entre sesiones.Gemini has three context levels: (1) Current conversation — everything said in this chat, up to 2M tokens. (2) Workspace context — access to Gmail, Drive, Docs when connected (AI Pro+). (3) Gems — persistent instructions that apply on every Gem use. Unlike ChatGPT which has explicit persistent memory across conversations, Gemini relies more on Workspace as a cross-session context source.
