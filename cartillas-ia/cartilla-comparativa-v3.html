Framework de Decision: Modelo ≠ Producto ≠ Plan ≠ App [DOC]Decision Framework: Model ≠ Product ≠ Plan ≠ App [DOC]

La confusion #1 al comparar herramientas de IA es mezclar estos 4 niveles:
Modelo: el motor de IA (GPT-5.4, Opus 4.6, Gemini 3.1 Pro). No lo usas directamente.
Producto: la interfaz que empaqueta el modelo (ChatGPT, Claude, Gemini app). Lo que realmente usas.
Plan: lo que pagas determina que modelo y que funciones obtienes (Free vs Pro vs Max).
App: la superficie especifica (web, mobile, CLI, IDE). El mismo producto puede comportarse diferente en cada app.
Cuando alguien dice "GPT-5 es mejor que Claude" esta mezclando modelo con producto. Las comparaciones utiles especifican: que modelo, en que producto, en que plan, en que superficie.The #1 confusion when comparing AI tools is mixing these 4 levels:
Model: the AI engine (GPT-5.4, Opus 4.6, Gemini 3.1 Pro). You don't use it directly.
Product: the interface that packages the model (ChatGPT, Claude, Gemini app). What you actually use.
Plan: what you pay determines which model and features you get (Free vs Pro vs Max).
App: the specific surface (web, mobile, CLI, IDE). The same product can behave differently on each app.
When someone says "GPT-5 is better than Claude" they are mixing model with product. Useful comparisons specify: which model, in which product, on which plan, on which surface.

Que es MCP y por que importa [DOC]What is MCP and why it matters [DOC]

MCP (Model Context Protocol) es un estandar abierto creado por Anthropic que define como un modelo de IA se comunica con herramientas externas (bases de datos, APIs, archivos, navegadores, calendarios). Es el equivalente de USB-C para IA: un conector universal. Un servidor MCP escrito una vez puede ser usado por cualquier cliente que soporte el protocolo.MCP (Model Context Protocol) is an open standard created by Anthropic that defines how an AI model communicates with external tools (databases, APIs, files, browsers, calendars). It is the USB-C equivalent for AI: a universal connector. An MCP server written once can be used by any client that supports the protocol.
