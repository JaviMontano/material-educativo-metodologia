## Decisiones de canon

- `canonical`: fuente publicada o usada como base directa del entregable final.
- `source-only`: fuente revisada para completar información o trazabilidad, sin publicarse completa.
- `legacy`: versión preservada como antecedente; no se publica para evitar duplicidad.
- `exclude`: fuera del alcance público general por cliente/contexto específico.

## Nota de publicación

El repo mantiene aliases raíz para no romper URLs existentes y agrega carpetas navegables por familia con README propio. Los JSON gigantes de la Biblioteca Universal se mantienen en raíz como canon para evitar duplicación innecesaria.
