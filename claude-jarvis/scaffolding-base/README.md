# Scaffolding base · Jarvis OS en Claude

Plantilla de clase para iniciar un Jarvis OS personal. Copia esta carpeta a tu repo de trabajo y ejecuta los prompts del ejercicio de clase.

## Estructura

- `CLAUDE.md` · contrato operativo del asistente.
- `MEMORY.md` · memoria de decisiones y avances.
- `TAREAS.md` · tablero simple NOW/NEXT/LATER.
- `_INDICE.md` · mapa navegable.
- `_ESTRUCTURA.md` · contrato de carpetas.
- `01_Estaciones/Contexto Profesional/` · primera estación para CV, perfil de cargo y preparación 1:1.
