# Preparación 1:1 con jefe / mentor

## Objetivo de la conversación

## 5 preguntas de preparación

1. ¿Qué resultado quiero lograr con esta conversación?
2. ¿Qué evidencia demuestra mi avance?
3. ¿Qué bloqueo necesito destrabar?
4. ¿Qué decisión o feedback necesito pedir?
5. ¿Cuál será el siguiente paso concreto?

## Checklist

- [ ] CV base actualizado.
- [ ] Perfil de cargo objetivo claro.
- [ ] Evidencias/anexos listos.
- [ ] Riesgos y dudas listados.
- [ ] Pedido concreto preparado.
