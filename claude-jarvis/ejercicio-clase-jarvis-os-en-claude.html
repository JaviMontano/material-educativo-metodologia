MetodologIA · Jarvis OS en Claude

Ejercicio de clase en 4 pasos

Una práctica guiada para iniciar tu configuración: calibrar, crear archivos base, montar la primera estación de contexto profesional y dejar una cadencia mínima. Cada paso incluye prompt en lenguaje natural, versión SPEC y dupla estándar System/User.

Inicio repo Jarvis OS Workbook Scaffolding base

Inputs iniciales y manejo de adjuntos

Antes de pedirle a Claude que ejecute, declara el objetivo, los materiales y los límites. El ejercicio asume que el repo contiene los HTML de clase en claude-jarvis/ y la Biblioteca Universal de Prompting en biblioteca/.

Parámetros mínimos
  • Nombre del participante.
  • Rol actual u objetivo.
  • Objetivo de la sesión 1:1.
  • Idioma operativo.
  • Alcance inicial: personal, profesional o mixto.
Adjuntos sugeridos
  • CV actual.
  • Perfil de cargo.
  • Notas de desempeño u OKR.
  • Feedback reciente.
  • Agenda de conversación con jefe.
Cláusulas de manejo
  • Leer adjuntos antes de resumir.
  • Distinguir evidencia de inferencia.
  • No copiar PII innecesaria.
  • Usar placeholders cuando haya sensibilidad.
  • Pedir confirmación antes de registrar.

Los 4 pasos de la práctica

01 · Calibración, preparación y priming

Alinear el objetivo de clase, declarar entradas disponibles y fijar cómo se van a tratar archivos y adjuntos antes de crear estructura.

Parámetros e inputs

  • Nombre del participante
  • Rol actual o rol objetivo
  • Objetivo de la sesión 1:1
  • HTML de clase y workbook disponibles en claude-jarvis/
  • Biblioteca Universal de Prompting disponible en biblioteca/

Adjuntos útiles

  • CV actual, si existe
  • Perfil de cargo o descripción de responsabilidades
  • Notas de desempeño, OKR o feedback reciente
  • Agenda o contexto de la próxima conversación con jefe
Prompt en lenguaje natural para usar en clase 
Actúa como facilitador de Jarvis OS en Claude para una clase práctica de MetodologIA. Antes de crear archivos, calibra el trabajo conmigo.

Inputs iniciales:
- Participante: [NOMBRE]
- Rol actual u objetivo: [ROL]
- Objetivo de la sesión 1:1 con mi jefe: [OBJETIVO]
- Ruta del repo de clase: [RUTA_REPO]

Si adjunto archivos, primero identifica qué son, qué información útil contienen y qué partes no deben copiarse literalmente. No reveles datos personales innecesarios. Si falta un insumo, pregúntame lo mínimo necesario.

Hazme 5 preguntas de calibración:
1. ¿Qué decisión o conversación concreta quiero preparar?
2. ¿Qué contexto profesional no quiero tener que repetirle a la IA cada vez?
3. ¿Qué evidencia tengo disponible para sostener mi historia profesional?
4. ¿Qué riesgo debo manejar con cuidado en esta preparación?
5. ¿Qué resultado útil debe quedar al final de la clase?

Al final, devuelve un resumen de priming con objetivo, materiales a usar, adjuntos detectados, límites de privacidad y siguiente paso recomendado.

02 · Crear archivos base del Jarvis OS

Crear el esqueleto operativo mínimo: reglas, memoria, tareas, índice y estructura para que el contexto empiece a ser portable.

Parámetros e inputs

  • Resumen de priming validado
  • Nombre de carpeta raíz
  • Preferencia de idioma
  • Alcance inicial: personal, profesional o mixto

Adjuntos útiles

  • Notas de contexto personal o profesional aprobadas
  • Lista de proyectos activos
  • Documentos de referencia que sí pueden resumirse
Prompt en lenguaje natural para usar en clase 
Actúa como facilitador de implementación. Con base en el priming validado, crea el scaffolding base de mi Jarvis OS.

Inputs iniciales:
- Carpeta raíz deseada: [NOMBRE_CARPETA]
- Idioma operativo: [ES/EN]
- Alcance inicial: [PERSONAL/PROFESIONAL/MIXTO]
- Materiales de apoyo: HTML de claude-jarvis/ y biblioteca/biblioteca-universal-prompting-2026-homologated.html.

Crea estos archivos en la raíz del repo de clase:
- CLAUDE.md: reglas operativas y cómo debe ayudarme Claude.
- MEMORY.md: log vivo de decisiones, aprendizajes y contexto confirmado.
- TAREAS.md: tablero simple de pendientes, NOW/NEXT/BLOCKERS.
- _INDICE.md: mapa navegable de archivos.
- _ESTRUCTURA.md: árbol y convenciones de carpetas.

Si hay adjuntos, resume solo lo necesario y deja trazabilidad de fuente. No pegues contenido sensible completo. Si no puedes escribir archivos directamente, entrégame bloques Markdown listos para crear.

Después de crear o proponer los archivos, valida que cada uno tenga propósito claro, sección de actualización y regla de uso.

03 · Crear primera estación: Contexto Profesional

Crear la primera estación de trabajo para CV, perfil de cargo y preparación de conversaciones profesionales.

Parámetros e inputs

  • CV base o resumen profesional
  • Perfil de cargo actual u objetivo
  • Objetivo de conversación 1:1
  • Logros, evidencias y tensiones relevantes

Adjuntos útiles

  • CV en PDF/DOCX
  • Descripción del cargo
  • Evaluación de desempeño
  • Feedback o notas de reuniones
Prompt en lenguaje natural para usar en clase 
Actúa como facilitador de contexto profesional. Crea la primera estación de mi Jarvis OS para preparar CV, perfil de cargo y una sesión 1:1 con mi jefe.

Inputs iniciales:
- CV o resumen profesional: [PEGAR O ADJUNTAR]
- Perfil de cargo actual u objetivo: [PEGAR O ADJUNTAR]
- Objetivo de la conversación 1:1: [OBJETIVO]
- Evidencia disponible: [LOGROS / METRICAS / FEEDBACK / PROYECTOS]

Crea esta estructura:
01_Estaciones/Contexto Profesional/
- CLAUDE.md
- MEMORY.md
- _INDICE.md
- contexto-profesional.md
- cv-base.md
- perfil-cargo.md
- preparacion-1a1-jefe.md

Manejo de adjuntos:
- Si adjunto CV, extrae perfil, experiencia, habilidades, logros y brechas. No inventes métricas.
- Si adjunto perfil de cargo, separa responsabilidades, expectativas, competencias y señales de éxito.
- Si adjunto feedback, clasifica fortalezas, riesgos y temas sensibles.
- Si algo es confidencial, resume con placeholders.

Entrega la estación con contenido inicial útil y una lista de 5 cosas que debo completar para dejarla operativa.

04 · Validar, registrar y dejar siguiente cadencia

Revisar que lo creado sea usable, registrar decisiones y dejar una cadencia mínima para mantener vivo el sistema.

Parámetros e inputs

  • Archivos creados
  • Resultado deseado de la próxima semana
  • Cadencia elegida: DBR o WBR
  • Pendientes críticos

Adjuntos útiles

  • Captura o listado del árbol creado
  • Notas de validación
  • Pendientes de la clase
Prompt en lenguaje natural para usar en clase

Inputs iniciales:

- Resultado deseado para la próxima semana: [RESULTADO]
- Cadencia inicial: [DBR/WBR]
- Pendientes críticos: [LISTA]

Valida:
1. Que CLAUDE.md tenga reglas accionables.
2. Que MEMORY.md registre decisiones y aprendizajes.
