## Politica PII-safe

No se publican notas privadas, transcripciones literales, correos, nombres de participantes, contratos, recibos ni empresas sensibles. Las memorias publicas usan roles, contextos y patrones reutilizables. La fuente privada queda fuera del repositorio.

## Deep links por herramienta

ChatGPT usa `https://chatgpt.com/?prompt=<encoded>` como patron operativo con respaldo de copia. Gemini usa `https://gemini.google.com/app` y copia el prompt para pegarlo manualmente. Claude web usa `https://claude.ai/new` y copia el prompt. Claude Desktop soporta `claude://claude.ai/new?q=<encoded>`, pero no se usa como CTA principal porque requiere app instalada.
