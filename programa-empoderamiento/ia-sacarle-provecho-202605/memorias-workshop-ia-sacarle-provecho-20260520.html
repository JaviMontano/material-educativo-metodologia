Tesis del taller

La IA produce mejor cuando recibe situación, pedido, forma de ejecución y criterios de evaluación. La herramienta importa, pero el método decide la calidad de la salida.

Resultado observable

En minutos aparecieron estructuras de presentaciones, borradores para audiencia ejecutiva y rutas para convertir objetivos laborales o de proyecto en narrativas accionables.

Aprendizaje crítico

Cuando faltan insumos, la IA debe preguntar. Cuando hay documentos, imágenes o contexto, puede contrastar alternativas, mejorar la narrativa y proponer formatos más útiles.

Método SPEC

Cuatro piezas para que la IA no trabaje a ciegas.

SPEC se usa aquí como estructura mínima para delegar tareas profesionales: define contexto, pedido, modo de ejecución y estándar de calidad.

Situación

Describe el escenario real: audiencia, objetivo, restricciones, insumos disponibles, decisión esperada y nivel de confidencialidad. Sin situación, la IA rellena vacíos con supuestos.

Pedido

Explica qué debe producir la IA y para qué se usará: presentación ejecutiva, estructura de slides, guion, preguntas para aclarar o contraste de alternativas.

Ejecución

Marca el proceso: primero preguntar si falta información, luego proponer estructura, después convertir a formato y finalmente revisar calidad contra criterios.

Criterios

Define cómo se evalúa la salida: claridad, brevedad, evidencia, utilidad para la audiencia, cero invenciones, formato editable y siguiente acción clara.

Flujo de práctica

La ruta para repetir el taller con un caso propio.

Este flujo convierte el workshop en rutina reutilizable. Sirve para presentaciones laborales, reportes ejecutivos, preparación de entrevistas o síntesis de investigación.

1

Elegir un caso

Define si trabajarás con un reto real o con un insumo de práctica.

2

Ordenar insumos

Reúne notas, agenda, captura, documento o brief. Si no hay insumos, dilo.

3

Usar SPEC

Pide preguntas antes de producir y exige supuestos marcados.

4

Generar estructura

Solicita narrativa, títulos y secuencia de slides para una audiencia concreta.

5

Convertir formato

Pide PPT, HTML, guion o notas de speaker según la herramienta disponible.

6

Revisar y iterar

Evalúa contra criterios, corrige alcance y repite con mejores datos.

Prompts de acción

Cuatro prompts listos para practicar.

Úsalos con ChatGPT, Gemini, Claude o NotebookLM. Reemplaza los campos entre corchetes antes de enviar.

1. Arranque sin inventar

Abrir GPT Gemini Claude
Actúa como asistente de trabajo ejecutivo.

Situación: Quiero preparar una presentación sobre [TEMA] para [AUDIENCIA]. Tengo estos insumos: [INSUMOS DISPONIBLES].

Pedido: Antes de producir la presentación, revisa si tienes información suficiente. Si falta un dato, no inventes: hazme máximo 5 preguntas o dime qué archivo debo adjuntar.

Ejecución: Primero lista lo que entendiste, luego los vacíos, luego una propuesta de objetivo y estructura.

Criterios: claridad, utilidad para decidir, supuestos marcados, cero datos inventados y siguiente paso concreto.

2. Presentación ejecutiva

Abrir GPT Gemini Claude
Rol: Actúa como estratega de presentaciones ejecutivas.
Contexto: Necesito convertir [INSUMO O IDEA] en una presentación breve para [AUDIENCIA] que debe decidir [DECISION].
Tarea: Propón una estructura de 5 a 7 diapositivas con título, mensaje central, evidencia necesaria y notas para quien presenta.
Reglas: No inventes cifras ni nombres. Si falta evidencia, márcala como pendiente. Mantén el lenguaje claro y directo.
Formato: Tabla con columnas: slide, título, mensaje, evidencia, nota del presentador.
Criterios: La presentación debe servir para decidir, no solo informar.

3. Revisión crítica

Abrir GPT Gemini Claude
Revisa esta presentación o estructura: [PEGAR CONTENIDO].

Evalúala como si fueras una audiencia ejecutiva con poco tiempo. Identifica:
1. Qué no se entiende.
2. Qué está débil o sin evidencia.
3. Qué sobra.
4. Qué decisión queda confusa.
5. Qué cambio haría más fuerte el cierre.

No reescribas todavía. Primero entrega diagnóstico y preguntas de aclaración.

4. Plan de práctica

Abrir GPT Gemini Claude
Ayúdame a practicar el flujo del workshop durante 60 minutos.

Mi caso es: [CASO].
Mis insumos son: [INSUMOS].
Mi herramienta será: [CHATGPT / GEMINI / CLAUDE / NOTEBOOKLM].

Diseña una sesión en 4 bloques: preparar contexto, generar estructura, convertir a formato, revisar calidad. Incluye tiempo sugerido, entregable de cada bloque y criterio de terminado.

FAQ

Preguntas que deja el workshop.

Estas respuestas sintetizan el criterio de la sesión sin convertir la transcripción en cita literal.

¿Necesito una herramienta paga para practicar?

No. La práctica funciona en capas gratuitas si el objetivo es aprender el flujo. Las versiones de pago pueden mejorar formatos, imágenes, archivos editables o capacidad de contexto, pero no reemplazan claridad, insumos y criterio humano.

¿Qué hago si la IA no genera un PowerPoint?

Pide primero estructura, títulos, mensajes y notas. Después solicita un formato exportable o copia la estructura a una herramienta de presentaciones. El entregable útil empieza por la narrativa, no por el archivo.

¿Puedo usar datos reales de trabajo?

Sí, solo si tienes permiso y si el contenido no expone información sensible. Para practicar, conviene anonimizar nombres, contratos, clientes, cifras privadas y cualquier dato que no deba salir de su contexto.

¿Qué debo llevar a la clínica?

Un caso, un borrador generado por IA, las preguntas que aparecieron y el punto donde el flujo se trabó. Eso permite trabajar sobre evidencia, no sobre teoría.
